# Basic Machine Learning Projects

A collection of beginner-friendly Python experiments exploring core concepts of Machine Learning, Deep Learning, and data processing using TensorFlow and Keras.

## 📁 Projects Included

1. **Digit Classifier (`digit_classifier.py`)**
   - **Description:** A simple neural network built with TensorFlow/Keras to classify handwritten digits using the famous MNIST dataset.
   - **Key Concepts:** Image preprocessing, flattening, dense layers, softmax activation, and model evaluation.

2. **Simple Linear Regression (`simple_regression.py`)**
   - **Description:** A foundational single-layer neural network designed to learn linear relationships and predict numerical values.
   - **Key Concepts:** Sequential models, loss functions (mean squared error), optimizers (SGD), and training epochs.

## 🛠️ Technologies Used
- **Language:** Python
- **Libraries:** TensorFlow, Keras, NumPy

## 🎯 Purpose
This repository showcases foundational hands-on learning and practical experimentation with building, compiling, and evaluating basic neural network models.
